# 技能质量优化器（CRAFT × Darwin 融合版）

面向已有技能的质量评估与优化工具。它结合 CRAFT 五维评分和 Darwin 九维评分方法，形成 10 维、100 分的统一评估体系，帮助完成技能审查、上架前检查、评分整改与优化验证。

## 能力

- 从规范性、可靠性、适用性、有效性、可信任度等维度评估技能质量。
- 输出扣分清单、修复方案和优化前后的评分明细。
- 提供安全敏感词扫描、中性词替换和 T-A 冲突解耦策略。
- 通过检查点和测试提示词支持可控的优化循环。

## 使用方式

将本目录作为技能目录导入支持 `SKILL.md` 的运行环境，然后通过自然语言请求评估或优化一个已有技能。例如：

```text
评估 /path/to/my-skill 这个技能的质量，先不改
```

或：

```text
帮我优化这个技能的质量评分，技能目录在 /path/to/my-skill
```
